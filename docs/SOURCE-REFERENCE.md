The original contains five top-level specification documents, 19 app page packages, one independent responsive website package, and three logos. It was safely extracted, including nested ZIP packages, with path-traversal and symlink checks. macOS metadata was excluded from extracted reference files; ZIP filenames with legacy encoding were normalized to UTF-8.

Implementation is independent of all other projects. Source credentials and temporary signed download links are not stored in this project. Original prototype scripts are reference material and are not executed as trusted build/install scripts. Visual assets bundled with the user-supplied product design are retained for this requested development; their redistribution rights should be verified before public release.
