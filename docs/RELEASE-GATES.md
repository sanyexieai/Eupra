# Release gates and explicit boundaries

This repository is an independent local engineering implementation based on Eupra MVP 1.0. A page existing is not proof that its product capability is live. The design handoff's full Definition of Done remains the acceptance target, not a statement of completion.

## Must not claim today

- A simulated concept is an AI-generated image or video.
- Bundled prototype cat artwork was generated from a newly uploaded photo.
- Local deterministic moderation is a production multimodal safety review.
- A disabled share button or blocked share endpoint completes the external viral loop.
- A quota table means real video generation is working.
- Creator-economy visuals represent real cash, settled earnings, or available withdrawals.
- A local SQLite/Tokio worker is deployed Postgres/Redis/object storage.
- Browser tests establish real-user humor quality, mobile-device testing, regulatory compliance, or payment readiness.

## Before real user pilot

1. Select and configure authorized image-generation and multimodal safety providers. Review their privacy/retention, cost limits, and processing geography.
2. Validate the implemented configurable V2 boundaries and real model behavior: Reality Parser, Possibility Miner, seed diversity, Taste Judge, Story Memory, visual director, final judge and safety gateway against real provider outputs.
3. Provide reliable storage, job recovery, backup/restore, service monitoring, rate limiting and session-security review.
4. Verify output provenance, visible and metadata AI labels, safety-gated sharing, share revocation, source-asset privacy and authorization for recipient remix.
5. Enable video only after real 5-second success/failure/cancellation and daily-credit reservation/settlement tests pass.
6. Run the design's 100-sample golden evaluation and real-user blind taste tests. Do not mark these as passed using fixtures.
7. Verify account verification/recovery, abuse controls, reporting and authenticated moderation operations.
8. Obtain any required brand, artwork and third-party material rights before distribution.
9. Confirm market-specific release policy. Default CN mode must not silently enable public community or creator payouts.
10. The user authorized source publication to sanyexieai/Eupra working branch. Deployment, default-branch merge and release remain separately unapproved.

## Payment/commerce constraints

Prices, provider selection, split percentages, video paid entitlements and payout date are not frozen in the design. No live payment or withdrawal is implemented or implied. Never use prototype amounts as production configuration.
